# CAMPUS LIFE

CAMPUS LIFE is a student workspace for managing coursework, class schedules,
campus announcements, and learning resources. It is a client-side React
application; student data and preferences are stored in the browser.

## Development

```sh
npm install
npm run dev
```

Run a production build and the linter with:

```sh
npm run build
npm run lint
```

See [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md) for the application structure,
features, and local data conventions, and [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)
for theme tokens, icon usage, and adding a theme.
